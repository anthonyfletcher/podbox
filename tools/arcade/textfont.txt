# The text font's own glyphs, beside Fusion Pixel 8 px's: the Greek and
# Cyrillic letters (Fusion's 8 px has none) and the accents every accented
# letter is composed from (Fusion's own accented capitals drop theirs).
# Read by gen_textfont.py.
#
# The cell is 12 rows: capitals stand on rows 3 to 8, lower case on 5 to 8,
# descenders reach rows 9 and 10, and accents sit above: rows 1 to 2 over a
# capital, row 3 (and 2) over a lower-case letter. Each glyph's advance is
# its width and one more.
#
#   glyph U+XXXX row      art from that row: # ink, . blank
#   same  U+XXXX U+YYYY   drawn as YYYY is (a letter shared with Latin)
#   mark  NAME            an accent's art, centred over the letter
#
# Marks are named by the combining character they stand for. An accent
# with a part below (cedilla, ogonek, comma, dot below) has art from row 0
# under the baseline.
